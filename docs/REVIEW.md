# Valorandomizer レビュー記録

最終レビュー日: 2026-08-02

## 結論

機能の核とビジュアル設計は良好です。一方、アジャイル開発で増えた機能が単一画面へ集中し、品質ゲート、モバイル操作、Pro Pickのルール整合、依存関係管理が追いついていませんでした。今回の整理で、日常開発を継続できる基盤とユーザー影響の大きい不具合を先に解消しています。

## 今回完了した項目

- Random PickとPro Pickを実ルートへ分離し、Proデータを必要な画面でだけ読み込む構成へ変更
- Pro Pickの2チームを必ず共通マップから抽選する純粋関数と単体テストを追加
- フィルター／モード／ロール構成変更後に古い結果を残さないよう状態整合を修正
- localStorageの履歴を型検証し、破損値や保存失敗で画面が落ちない外部ストアへ分離
- `.open-next`などの生成物をLint対象外にし、`pnpm check`を品質ゲートとして追加
- Next.jsを16.2.12へ更新し、直接該当していた既知脆弱性を解消
- スマートフォンの言語切替はみ出し、隠れていたカード操作、Pro画面の中間幅崩れを修正
- ロール操作名、現在言語、フォーカス表示、結果通知、動きを減らす設定を改善
- 韓国語のController/Sentinel誤訳とPro Pick内の未翻訳表示を修正
- locale別metadata、基本セキュリティヘッダー、現状に一致するREADMEを追加

## 今回の検証結果

- `pnpm check`: Lint、型検査、単体テスト9件が成功
- `pnpm build`: 3言語 × 3ルートの静的生成を含めて成功
- `pnpm cf:build`: Next.js側のビルドと静的生成は成功。後段のOpenNext bundleは、Windows上で生成したシンボリックリンクの読み取りが拒否されて停止した。権限制限外でも再現し、OpenNext自身もWindows非完全互換とWSL利用を警告しているため、Linux CIまたはWSLで最終確認する
- `pnpm audit --prod`: 開始時の17件から、Next.js更新と限定的なoverrideにより1件へ削減。残件はNext.js経由のoptional `sharp@0.34.5`で、互換性を確認せず0.35系へ強制更新しない例外として記録する

## 残課題（優先順）

### P1: 画像配信量

29枚のportraitは合計約20.9MB、平均約721KBで、Cloudflare向け設定では原寸PNGを配信します。Random Pickの5体で平均約3.6MB、Pro Pickの10体で約7.2MBです。

次のどちらかを選択します。

1. 同期時に320px/640pxのWebPまたはAVIFを事前生成する
2. Cloudflare Images / Image Resizingとcustom loaderを使う

費用と運用依存が異なるため、デプロイ方針を決めてから実装します。

### P1: エージェント同期の安全性

`agents:sync`は既存画像を削除してから逐次取得するため、中断時に部分状態になります。一時ディレクトリへの全件取得、API・URL・Content-Type・サイズ検証、成功時のみ入れ替えるトランザクショナル方式へ変更します。

### P1: 自動品質ゲート

GitHub Actionsで以下を必須化します。

1. frozen install
2. `pnpm check`
3. `pnpm build`
4. `pnpm cf:build`
5. 本番依存監査

### P2: 画面テスト

Playwrightで3言語、2モード、同一マップ抽選、固定／引き直し、履歴、不正localStorage、モバイル幅をカバーします。現状の単体テストはドメインロジック中心です。

### P2: Proデータ一覧と履歴

- 最大2,620行の一覧をA/Bタブとページングへ変更
- フィルター候補を事前索引化し、選択肢ごとの全件走査を削減
- 保存上限100件に対し5件しか見えない履歴へ、全件表示・日時・エクスポートを追加
- 全消去にUndoを追加

### P3: 運用整理

- Node/pnpmバージョンをCIと本番で固定
- `global-error.tsx`と404 UIを追加
- CSPはデプロイ先のスクリプト要件を確認後に導入
- 未使用のHikomiフォント、未使用翻訳キー、古いスクリーンショットを所有者確認後に整理
- Next.js由来のoptional `sharp`監査警告は、互換版が出た時点で更新

- 受け入れ条件がテストで表現されている
- `pnpm check`、`pnpm build`、`pnpm cf:build`が成功する
